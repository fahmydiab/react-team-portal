# Team Portal

A React and TypeScript portal for browsing projects. Members can view projects, and admins can change the compact-list setting.

## Prerequisites

- Node.js and npm (use a Node.js version supported by Vite 8)

## Install and run

From the project directory:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173/`). Sign in with `sara` for an admin account or `youssef` for a member account. The mock API can occasionally fail; retry the request if needed.

## Other commands

```sh
npm run test    # Run the Vitest tests
npm run lint    # Check lint rules
npm run build   # Type-check and create a production build
npm run preview # Serve the production build locally after building
```
